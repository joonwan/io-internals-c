## Non blocking 인 이유

```c
static void set_nonblocking(int fd)
{
    int flags = fcntl(fd, F_GETFL, 0); // 현재 flag 읽기
    if (flags == -1)// fcntl 실패
    {
        perror("fcntl F_GETFL");
        exit(EXIT_FAILURE);
    }

    flags |= O_NONBLOCK; // O_NONBLOCK 추가 -> 기존 설정 유지 + non-blocking 옵션 붙이기
    
    if (fcntl(fd, F_SETFL, flags) == -1) // 새 flag 값 fd 에 적용 실패할 경우
    {
        perror("fcntl F_SETFL");
        exit(EXIT_FAILURE);
    }

    printf("[설정] fd=%d non blocking mode 활성화\n", fd);
}
```

```c
ssize_t n = read(pipefd[0], buf, sizeof(buf) - 1);
```

`fcntl()` 을 통해 읽기 fd 에 `O_NONBLOCK` 플래그를 설정한다. 그 결과 child process 가 `read()` 를 호출했을 때 데이터가 없으면 기다리지 않고 즉시 반환한다. 즉 실행 흐름이 `read()` 안에서 멈추지 않기 때문에 non blocking 이다.

## Synchronous 인 이유

child process 는 작업 완료를 나중에 통지받는 것이 아니라, 직접 `read()` 를 반복 호출하면서 결과를 확인한다. 그리고 읽기에 성공한 시점에 맞춰 이후 로직을 실행하므로 synchronous 하다.
